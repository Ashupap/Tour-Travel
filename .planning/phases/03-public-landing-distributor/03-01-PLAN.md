# Plan 03-01: Three.js Hero 3D Bus Experience & Public Landing Shell

<threat_model>
- **Threat:** Malicious or oversized 3D asset downloads stalling page load times (> 1.5s on 4G) or consuming excessive client GPU/battery resources.
  - **Mitigation:** Deliver Three.js locally via `pb_public/js/three.min.js`; construct a procedural Bharat luxury sleeper coach using optimized Three.js geometries and shaders with 0 KB external GLB network requests; pause `requestAnimationFrame` when the canvas is scrolled out of viewport.
- **Threat:** Unresponsive UI rendering on low-tier mobile hardware during scroll events.
  - **Mitigation:** Use passive scroll listeners and dampening linear interpolation (`lerp`) to decouple scroll events from 60fps render ticks.
</threat_model>

## Objective
Deliver the public landing page shell at `/` featuring a high-performance Three.js r128 3D luxury sleeper bus canvas in the hero section that smoothly animates and navigates along a spline curve as the visitor scrolls down the page (`LAND-01`).

<action>
In `pb_public/js/bus-3d.js`, build a modular Three.js rendering module:
1. Initialize WebGLRenderer with `antialias: true, alpha: true, powerPreference: "high-performance"`.
2. Construct detailed procedural Bharat luxury sleeper bus:
   - Aerodynamic chassis with metallic saffron gold livery (`#D97706` / `#F59E0B`) and dark lower trim.
   - Tinted panoramic windows with subtle warm interior lighting.
   - Dual-axle wheels with rubber tires and chrome hubs.
   - Front chrome grill, LED headlights, side mirrors, and "BharatYatra" logo banner.
3. Configure lighting: soft ambient light, warm directional sunlight with soft shadows, and subtle ground road reflection.
4. Construct a Catmull-Rom 3D spline curve defining the highway trajectory.
5. Track page scroll progress and interpolate the bus position, steering angle, and camera zoom along the curve.
6. Use `IntersectionObserver` to pause rendering when the hero canvas is out of the viewport.
</action>
<acceptance_criteria>

- Bus rotates and translates along the curve in response to scroll.
