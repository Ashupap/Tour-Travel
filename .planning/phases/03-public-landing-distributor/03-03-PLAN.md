# Plan 03-03: Public Booking Status Lookup & Golden Travel Eligibility Pass

<threat_model>
- **Threat:** Enumeration of customer phone numbers or private subscriber financial data by unauthorized crawlers.
  - **Mitigation:** Rate-limit status queries or require exact 10-digit phone or exact booking code match (`BY-YYYY-XXXX`); do not expose sensitive internal database fields (mask middle digits of phone `98XXXX1234`).
- **Threat:** Tampered or fraudulent screenshot representation of travel clearance.
  - **Mitigation:** Render the golden Travel Eligibility Pass with server-verified status, unique verification token, official timestamps, and itemized receipt slip IDs.
</threat_model>

## Objective
Implement the public "Check Booking Status" modal allowing customers to look up their booking by phone or booking code without logging in, rendering a luxury golden Travel Eligibility Pass with dynamic travel status and downloadable payment slips (`LAND-04`, `LAND-05`).

## Tasks

<task>
<name>Implement Public Booking Status API Route</name>
<read_first>
- PRD.md (Section 4.1: Customer Eligibility Pass Modal)
- .planning/phases/03-public-landing-distributor/03-RESEARCH.md (Section 3)
</read_first>
<action>
In `pb_hooks/07_public_routes.pb.js`, register `GET /api/public/booking-status`:
1. Parse query parameter `query` (phone number or booking code).
2. Clean and format query string. Return HTTP 400 if empty.
3. Query `subscriptions` collection matching `booking_code = query` OR `customer_phone = query`.
4. If not found, return HTTP 404 with friendly message: *"No active booking found for this reference or mobile number."*
5. If found:
   - Query package details (`title`, `destination`, `duration_days`, `min_emis_to_travel`).
   - Query all installments for this subscription sorted by `installment_no ASC`.
   - Calculate total paid, remaining balance, and required EMIs to unlock travel.
   - Mask customer phone (e.g. `98765*****`).
   - Check if request is from HTMX (`c.request().header.get("HX-Request") === "true"`):
     - If HTMX: render and return the Golden VIP Travel Eligibility Pass HTML snippet.
     - If JSON: return `{ success: true, subscription, package, installments, eligibility }`.
</action>
<acceptance_criteria>
- `GET /api/public/booking-status?query=INVALID` returns 404 with error message.
- `GET /api/public/booking-status?query=<VALID_CODE>` returns verified subscription, package, and installment history.
</acceptance_criteria>
</task>

   - Payment history table / list showing each installment, due date, amount, payment mode, and verified Receipt Slip ID (`SLIP-YYYYMM-XXXX` or `OFF-...`).
