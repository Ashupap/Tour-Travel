# Plan 03-05: Distributor Handover Approval Panel & Phase 3 Verification Suite

<threat_model>
- **Threat:** Cash handover verified by the wrong distributor or verified with an incorrect/guessed OTP code.
  - **Mitigation:** Ensure `POST /api/handover/verify` validates both `distributor_id = auth.id` and exact match on the random 4-digit `otp_code` generated during handover initiation.
- **Threat:** Regressions in Phase 1 data integrity or Phase 2 agent offline sync flows during public landing or distributor development.
  - **Mitigation:** Execute automated Phase 1 and Phase 2 test suites alongside a comprehensive Phase 3 verification suite covering all 9 Phase 3 requirements.
</threat_model>

## Objective
Implement the Pending Handovers panel in the Distributor dashboard for verifying agent cash handovers with OTP input, and write the comprehensive automated Phase 3 integration test suite (`tests/phase3_verification.js`).

<action>
In `pb_hooks/08_distributor_api.pb.js`, implement `GET /api/distributor/pending-handovers`:
