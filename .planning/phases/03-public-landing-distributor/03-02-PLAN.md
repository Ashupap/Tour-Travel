# Plan 03-02: Package Catalog with Vanilla-Tilt 3D Cards & Dynamic EMI Calculator

<threat_model>
- **Threat:** Malcalculated EMI amounts displayed to public customers causing price discrepancy disputes.
  - **Mitigation:** Calculate EMIs strictly from verified package total price and allowed tenures using standard mathematical rounding; display transparent cost breakdown and travel threshold milestone.
- **Threat:** Heavy DOM manipulation or JavaScript locks during card hovering causing page lag.
  - **Mitigation:** Vanilla-Tilt operates with hardware-accelerated CSS 3D transforms (`transform: perspective(...) rotateX(...) rotateY(...)`) without triggering browser reflows.
</threat_model>

## Objective
Implement an interactive tour package catalog featuring 3D tilt cards powered by Vanilla-Tilt.js (`glare: true, maxGlare: 0.35, speed: 400`) and a real-time Alpine.js EMI calculator showing monthly installments and travel unlock thresholds (`LAND-02`, `LAND-03`).
