# Plan 03-04: Distributor Dashboard: Territory Analytics, Agent Roster & Delinquency Warnings

<threat_model>
- **Threat:** Cross-territory data leakage where a distributor views subscriber, financial, or agent metrics belonging to another territory.
  - **Mitigation:** Strictly enforce `distributor_id = @request.auth.id` across all queries and API responses (`SEC-03`, `SEC-04`); query the `distributor_daily_analytics` view filtered explicitly by authenticated distributor ID.
- **Threat:** Unauthenticated access to business metrics or agent performance rosters.
  - **Mitigation:** Require valid Bearer token / auth record with `role IN ('distributor', 'admin')`; return HTTP 401/403 for unauthorized requests.
</threat_model>

## Objective
Build the Distributor territory management dashboard at `/distributor/dashboard`, presenting aggregated recovery metrics from `distributor_daily_analytics`, subordinate agent performance rosters, and a 30+ day delinquent accounts watchlist (`DIST-01`, `DIST-03`, `DIST-04`).

<action>
In `pb_hooks/08_distributor_api.pb.js`, implement custom endpoints with role validation (`SEC-04`):
1. `GET /api/distributor/analytics`:
   - Validates user has role `distributor` (or `admin`).
   - Queries `distributor_daily_analytics` view for row matching `distributor_id = auth.id`.
   - Returns: `{ total_active_subscriptions, total_overdue_amount, collected_today, cash_in_agents_custody }`.
2. `GET /api/distributor/agents`:
   - Queries `users` where `role = 'agent' AND distributor_id = auth.id`.
   - For each agent, calculates:
     - Today's collections (`payment_mode` cash & upi).
     - Current physical cash in custody (`handover_status = 'agent_custody'`).
     - Number of assigned active subscriptions and overdue accounts.
   - Returns sorted agent performance roster.
3. `GET /api/distributor/delinquents`:
   - Queries `subscriptions` where `distributor_id = auth.id`.
   - Identifies installments overdue by > 30 days (`due_date < (today - 30 days)` and `status IN ('pending', 'overdue')`).
   - Returns delinquent accounts list with customer name, phone, days overdue, outstanding amount, and assigned agent.
</action>
<acceptance_criteria>
- `GET /api/distributor/analytics` returns HTTP 401 when unauthenticated and HTTP 403 for agents.
- For authenticated distributors, metrics match their territory data.
- Delinquent accounts list filters correctly for > 30 days overdue.
</acceptance_criteria>
</task>
