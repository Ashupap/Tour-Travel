# Plan 04-03: Bus Manifest Export (CSV & Printable)

<threat_model>
- **Threat:** Manifest exposing passenger PII to non-admin users.
  - **Mitigation:** `requireAdmin(c)` guard on every manifest route (`SEC-04`); returns 401/403 before any query executes.
- **Threat:** CSV injection via customer names (formula prefixes `=`, `+`, `-`, `@`) opening as executable formulas in Excel.
  - **Mitigation:** Prefix such cells with a single quote (`'`) before quoting, keeping data readable and inert.
- **Threat:** Malformed CSV (unescaped commas/quotes/newline in names or Odia text) corrupting columns.
  - **Mitigation:** RFC-4180 quoting for every field containing `,`/`"`/newline, UTF-8 BOM for Excel, CRLF line endings.
</threat_model>

## Objective
Let an admin select a tour/package and export the full passenger manifest with payment status as a CSV download and a printable HTML view (`ADMN-04`).

<read_first>
- .planning/phases/04-admin-dashboard-polish/04-RESEARCH.md (Section 4)
- pb_migrations/1726940001_initial_schema.js (subscriptions/installments schema)

<action>
In `pb_hooks/09_admin_api.pb.js` implement `GET /api/admin/manifest?tour=<package_id>`:
1. `requireAdmin(c)` guard; reject missing/unknown `tour` with 400/404.
2. Query `subscriptions` where `package_id = {tour}`, sorted by `booking_code`.
3. For each subscription, aggregate installments: `emis_paid`, `total_emis`, `amount_paid`, `outstanding = total_amount - amount_paid`, `last_payment_at` (max `paid_at`), `travel_status`.
4. Return `{ package: {...}, passengers: [...], generated_at }`.
</action>
<acceptance_criteria>
- Returns one row per subscription for the selected package with correct paid/outstanding amounts.
- Anonymous and non-admin tokens receive 401/403.
</acceptance_criteria>
</task>

<task>
<name>Implement CSV Export Endpoint</name>
<read_first>
- .planning/phases/04-admin-dashboard-polish/04-RESEARCH.md (Section 4)
</read_first>
<action>
Implement `GET /api/admin/manifest?tour=<package_id>&format=csv` in `pb_hooks/09_admin_api.pb.js`:
1. Reuse the manifest data builder from the JSON endpoint.
2. Emit header: `Booking Code,Customer,Phone,Package,Tenure (Months),EMIs Paid,Total EMIs,Amount Paid (INR),Outstanding (INR),Travel Status,Last Payment`.
3. RFC-4180 quote fields, CRLF endings, prefix formula-leading cells with `'`, prepend UTF-8 BOM.
4. Respond with `Content-Type: text/csv; charset=utf-8` and `Content-Disposition: attachment; filename="manifest-<package-slug>-YYYY-MM-DD.csv"`.
</action>
<acceptance_criteria>
- Response is `text/csv` with attachment disposition and a dated filename.
- Body starts with the BOM, header row matches the spec, and each passenger occupies exactly one row.
- Fields containing commas/quotes are correctly escaped.
</acceptance_criteria>
</task>
