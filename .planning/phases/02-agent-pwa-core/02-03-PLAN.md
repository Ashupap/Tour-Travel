# Plan 02-03: Agent Dashboard Layout & Collection Workflows

<threat_model>
- **Threat:** Sensitive subscriber phone numbers or addresses stored unencrypted in DOM accessible to malicious scripts.
  - **Mitigation:** Render subscriber data cleanly without exposing sensitive authentication tokens or raw password hashes.
- **Threat:** Duplicate form submissions on slow or fluttering network connections double-charging customers.
  - **Mitigation:** Disable submit button upon initial tap in Alpine.js component and attach a unique idempotency key before submitting.
</threat_model>

## Objective
Build the mobile-responsive Agent Dashboard served by PocketBase at `/agent/dashboard` using Tailwind CSS, HTMX, and Alpine.js, featuring the daily recovery list, "Collect EMI" modal, live online/offline status pill, and manual sync trigger.
