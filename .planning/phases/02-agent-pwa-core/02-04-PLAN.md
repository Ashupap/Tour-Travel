# Plan 02-04: Thermal Receipt Preview, WhatsApp Sharing & Cash in Hand Widget

<threat_model>
- **Threat:** URL tampering in WhatsApp deeplinks allowing forged payment messages.
  - **Mitigation:** Generate WhatsApp share message strictly from validated receipt data with unique slip ID (`SLIP-YYYYMM-XXXX` or `OFF-{agent_id}-{timestamp}`).
- **Threat:** Receipt layout rendering improperly on small portable Bluetooth thermal printers (58mm/80mm).
  - **Mitigation:** Use strict CSS `@media print` rules with monospaced font (`Courier New`), fixed max-width 300px, explicit text alignments, and dashed dividers.
</threat_model>

## Objective
Implement the thermal receipt modal, WhatsApp share deeplink generator, and the "Cash in Hand" total summary widget with handover initiation controls on the Agent Dashboard.
